# Elegant Writer — demandes de code source

Elegant Writer est une application de bureau pour écrire des romans et des scénarios. Son code n'est pas public.
Pour certaines fonctions (export PDF, polices, césure), l'application intègre des bibliothèques tierces sous licence
GNU LGPL (version 2.1 ou ultérieure).

Ce dépôt sert de point de contact pour l'offre écrite de code source que la licence LGPL prévoit.

## Demander le code source

1. Ouvrez un ticket dans l'onglet **Issues** de ce dépôt.
2. Indiquez la version d'Elegant Writer que vous avez reçue et la ou les bibliothèques qui vous intéressent.
   Leur liste figure dans les mentions de licence de l'application.

Pendant au moins trois ans à compter de la date où vous avez reçu l'application, l'éditeur d'Elegant Writer
fournit à quiconque en fait la demande une copie complète, lisible par machine, du code source correspondant à ces
bibliothèques telles qu'elles sont livrées. Seuls les frais réels de distribution physique peuvent être facturés.

Le code source de ces bibliothèques est aussi disponible auprès de leurs projets d'origine, cités dans les mentions
de licence de l'application.

# Elegant Writer — source code requests

Elegant Writer ships third-party libraries licensed under the GNU LGPL (2.1 or later). This repository is the
contact point for the written source offer: open an issue naming your Elegant Writer version and the libraries you
want the corresponding source code for.
